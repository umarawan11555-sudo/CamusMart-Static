# CampusMart Static

CampusMart is a static website built with HTML5 form CS554 Lecture 1.
It has 3 pages: home (browse listings), sell (post an item), and about.

## How to Use
Open index.html in any browser, or run with Live Server in VS Code.
Click "Sell an item" to see the form, or "About" for more info.

## Pages
- index.html - Home page with latest listings
- sell.html - Form to post a new item
- about.html - About CampusMart
